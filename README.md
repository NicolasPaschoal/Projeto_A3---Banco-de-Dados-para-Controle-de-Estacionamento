Projeto A3 - Banco de Dados para Controle de Estacionamento
Sobre o projeto

Este projeto tem como objetivo desenvolver um banco de dados, contemplando as etapas de modelagem conceitual, lógica e física. Ao final, o trabalho será apresentado como nosso Projeto A3, para a conclusão do semestre na Universidade São Judas Tadeu – Campus Butantã.
