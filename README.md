# Projeto A3 - Banco de Dados para Controle de Estacionamento

## 📌 Sobre o projeto

Este projeto tem como objetivo desenvolver um banco de dados, contemplando as etapas de modelagem conceitual, lógica e física. Ao final, o trabalho será apresentado como nosso **Projeto A3**, para a conclusão do semestre na **Universidade São Judas Tadeu – Campus Butantã**.

## 📁 Estrutura do projeto

- `docs/`: Documentação e diagramas do projeto.
- `sql/`: Scripts SQL utilizados na implementação.

## 🚀 Etapas do desenvolvimento

1. Modelagem conceitual (DER).
2. Modelagem lógica.
3. Modelagem física.
4. Implementação do banco de dados.
5. Inserção de dados.
6. Desenvolvimento de consultas SQL.

## 🛠️ Tecnologias utilizadas

- SQL
- SQLite
